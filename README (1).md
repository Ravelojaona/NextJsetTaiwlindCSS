# React challenge 1: To-Do List App

## Objective

Design and implement a basic To-Do list app using React. The application should
have the following functionalities:

- Display a list of tasks, each with a name, description, status, due date, and
  assigned person
- Allow users to create, delete, and edit tasks and their details
- Implement the ability to add tags to tasks for better organization
- Provide sorting and filtering options for tasks in the user interface

Ensure users are authenticated with a username and password. You must implement
a mechanism allowing them to only modify the tasks they created, and view tasks
assigned to them.

### Bonus

Feel free to add extra features to impress, such as attaching files to tasks or
sending email reminders for overdue tasks.

## Constraints

Use [Next.js](https://nextjs.org/) 14 and [Auth.js](https://authjs.dev). You can
use any additional library but be ready to justify your choices. Note that you
cannot use "managed" services like Firebase or Supabase.

## Instructions

1. Fork this repository
2. Create a new branch for your work
3. Commit and push your changes to your fork
4. Update the README with instructions on how to run your code
5. When ready, create a pull request with a high-level description of your

6. Email us to let us know you are done

Note that in case there are external environment variables, such as credentials
for an SMTP proxy, those should be clearly stated in the README.
